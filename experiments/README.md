# Experiments

Experiment records. A Completed Experiment is complete evidence, not necessarily
a successful outcome, and may publish independently of an unpublished subject.

Naming:
`YYYY-MM-DD - Dish Trial.md`

Rules:
- Use `templates/Experiment - Template.md`.
- Follow the four exact primary-subject forms in the
  [authoring contract](../docs/authoring-contract.md#experiment-contract).

# Project Preparation Groups from Existing Phases

The Modernist Cuisine reference groups ingredients alongside the procedure that
uses them. Each preparation group on the website will project exactly one
existing Phase: its Ingredient Uses sit beside its Method, and its heading and
supporting knowledge remain attached. This preserves the canonical Recipe's
authored relationships without inferring finer ingredient-to-step associations.

Splitting a Phase into several groups would require explicitly authored
associations that the current contract does not provide. The chosen projection
requires no new grouping metadata in canonical Markdown. It must also preserve
Phases with no new Ingredient Uses and distinguish Phase Outputs from Ingredients.

Accepted by the repository owner on 2026-10-05 during the design interview.
